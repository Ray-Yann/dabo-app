# LOBA Assistant DABO — Phase 1

Lecture seule du foyer actif. Nouvelle route `/api/loba/household` authentifiée par le jeton Supabase et vérification serveur de l'appartenance au foyer avant toute lecture. LOBA reçoit les tâches en attente, courses à acheter, événements du foyer, événements personnels du membre connecté et équilibre confirmé sur 30 jours. Aucune écriture en base.

Après installation : `npm run verify`, puis déploiement et tests réels avec plusieurs foyers si possible.
