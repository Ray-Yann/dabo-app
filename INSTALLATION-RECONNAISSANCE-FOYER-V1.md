# DABO V2 — Reconnaissance du foyer V1

Copier les dossiers `app`, `lib` et `tests` dans la racine de `dabo-app` et accepter la fusion/remplacement.

Aucune migration Supabase. Aucune nouvelle dépendance.

Le module distingue cinq états descriptifs : construction, amélioration observée, équilibre, dynamique partagée et activité. Il ne crée aucun score, classement ou causalité attribuée à une action DABO.

Après copie, lancer `npm run verify` dans l'environnement local DABO habituel.
