# DABO — Onboarding Valeur V1

Patch minimal de présentation de la valeur avant inscription.

- Deux écrans courts expliquent d'abord le problème humain puis la réponse DABO.
- Le premier constat est sourcé par EIGE CARE Survey 2024 (plus de 65 000 répondants, 27 États membres).
- Lors de la création du foyer, la preuve s'adapte au type déjà supporté par DABO : couple, famille ou colocation.
- Couple : données EIGE par type de foyer.
- Famille : Journal of Marriage and Family, N=3000 parents, batterie de 21 tâches cognitives domestiques.
- Colocation : étude publiée dans Australian Journal of Psychology sur les dynamiques de logement partagé de jeunes adultes.
- Les sources originales sont directement consultables depuis l'interface.
- Aucune causalité produit n'est revendiquée et DABO n'impose pas de norme 50/50.
- Le lien d'invitation conserve son parcours existant et utilise un CTA direct « Rejoindre le foyer ».
- 21 nouvelles clés sont traduites dans les 7 catalogues DABO.
- Aucune migration SQL.

Après copie : `npm run verify`.
