# DABO — Utilisateurs & Foyers V2

1. Copier `page.tsx` dans `app/admin/page.tsx` à la racine du projet DABO.
2. Accepter le remplacement.
3. Lancer `npm run verify`.

Aucune migration Supabase et aucune variable d'environnement ne sont nécessaires.

Cette version ajoute : compteurs opérationnels, recherche + filtres de statut, statuts Sans foyer / Multi-foyers / Collaboratif, dernière connexion et dernière activité, ainsi qu'une synthèse d'usage 30 jours par foyer.
