# DABO Visual Identity V1.1

Base attendue : Visual Identity V1 déjà installée et déployée.

## Installation
Copier le contenu de ce ZIP à la racine du projet DABO et accepter le remplacement des fichiers.

## Changements
- Tâches : couleur du membre utilisée comme accent discret du groupe.
- Courses : en-têtes magasins plus identifiables, sans logos de marques.
- Calendrier : cartes partagées/personnelles/du jour mieux signées visuellement.
- Navigation mobile : protection renforcée du libellé « Calendrier » contre la troncature.
- Micro-interactions V1 conservées.
- Aucune migration Supabase.
- Aucune nouvelle clé i18n.

## Validation
Exécuter `npm run verify` puis contrôler la production sur mobile et desktop avant tout PASS Production UX.
