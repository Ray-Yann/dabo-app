# DABO Home V1.2 — Vue rapide du foyer V1

Base : dabo-app-PROPRE-20260910-165953.zip

## Contenu
- ajoute une Vue rapide du foyer sous « L’essentiel aujourd’hui » ;
- 4 cartes compactes : Tâches, Courses, Calendrier, Budget ;
- chaque carte ouvre directement la surface correspondante ;
- Tâches = tâches actives du foyer ;
- Courses = articles actifs du foyer, pas seulement ceux du membre courant ;
- Calendrier = événements du foyer dans les 7 prochains jours ;
- Budget = factures en attente ;
- aucune modification de l’Attention Engine, LOBA, contributions, récurrences, RLS ou Supabase ;
- traductions ajoutées dans les 7 langues DABO.

Aucune migration Supabase.

Après copie du contenu du ZIP à la racine du projet :

```powershell
npm run verify
```
