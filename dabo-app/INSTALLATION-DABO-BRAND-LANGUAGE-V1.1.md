# DABO Brand Language V1.1 — La forme devient interface

Base requise : DABO Brand Language V1 déjà installé.

Copier le contenu de ce dossier à la racine du projet en remplaçant les fichiers existants.

Puis lancer :

```powershell
npm run verify
```

Résultat attendu : 194/194 tests, 606 clés × 7 langues, TypeScript PASS, Build PASS.

Aucune migration Supabase. Aucune nouvelle clé de traduction.

Cette version :
- étend l’orbite DABO à Tâches et Courses ;
- donne aux actions principales une silhouette organique asymétrique ;
- applique cette géométrie aux surfaces DABO clés et aux états vides ;
- conserve les couleurs membres comme langage humain du foyer ;
- ne multiplie ni logos, ni illustrations, ni décorations.
