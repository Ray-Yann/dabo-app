# LOBA IA V1.3 — intention conversationnelle et garde-fou numérique

## Objectif
- Une question simple reçoit une réponse simple et naturelle.
- Une demande d'analyse, de stratégie ou d'investisseur active une profondeur adaptée.
- Aucun chiffre concernant DABO ne doit être affirmé s'il n'est pas fourni par le cockpit ou l'utilisateur.
- Les effets attendus d'une fonctionnalité restent des hypothèses tant qu'ils ne sont pas mesurés.

## Installation
Copier les fichiers de ce correctif à la racine de `dabo-app` en acceptant les remplacements, puis lancer :

```powershell
npm run verify
```

Aucun SQL. Aucune nouvelle variable Vercel. Aucun nouveau package npm.
