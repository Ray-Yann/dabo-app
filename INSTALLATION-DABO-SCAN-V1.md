# DABO Scan V1 — socle d'import

Copier le contenu de ce dossier à la racine de `dabo-app` et accepter les remplacements.

Cette étape ajoute l'onglet Scanner à côté de Courses et Promos, les quatre types de documents (ticket, liste, brochure promo, facture/document), la prise de photo mobile, l'import image/PDF, l'aperçu et la règle de confirmation utilisateur.

Important : cette étape ne prétend pas encore lire le document. Le bouton de lecture reste volontairement désactivé jusqu'à l'intégration du moteur de compréhension documentaire. Aucun faux OCR n'est simulé.

Validation :

    npm run verify
