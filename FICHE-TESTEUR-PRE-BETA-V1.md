# DABO — TEST PRE-BETA

Merci de participer au test de DABO.

DABO est encore en phase de test. L'objectif est justement de découvrir ce qui fonctionne bien, ce qui n'est pas clair et ce qui peut poser problème dans une utilisation réelle.

## Comment tester DABO ?

Utilisez l'application comme vous le feriez naturellement dans votre foyer.

Nous ne vous demandons pas de suivre un scénario précis ni d'essayer toutes les fonctions.

Vous pouvez par exemple utiliser DABO lorsqu'une vraie situation se présente chez vous : une tâche à faire, des courses à prévoir, un événement à retenir ou quelque chose à organiser avec les autres membres du foyer.

Si vous êtes plusieurs dans votre foyer, invitez au moins une autre personne à utiliser DABO avec vous.

## Très important

Si vous ne comprenez pas quelque chose, ne cherchez pas forcément à obtenir immédiatement une explication.

Notez plutôt :

- ce que vous vouliez faire ;
- ce que vous avez essayé de faire ;
- ce qui vous a bloqué ou surpris.

Si quelque chose vous paraît évident et agréable à utiliser, dites-le également.

Il n'y a pas de mauvaise façon de tester DABO.

C'est l'application que nous testons, pas vous.

## Pendant le test

Essayez autant que possible d'utiliser DABO dans de vraies situations plutôt que de créer uniquement de fausses données pour le test.

Si vous rencontrez un problème technique, vous pouvez faire une capture d'écran.

Si une erreur empêche complètement de continuer, signalez-la immédiatement.

Pour les autres remarques, vous pouvez simplement les noter afin de nous les transmettre ensuite.

## Ce qui nous intéresse

Nous voulons notamment comprendre :

- ce que vous avez compris de DABO au premier contact ;
- ce que vous avez utilisé naturellement ;
- ce que vous n'avez pas utilisé ;
- ce qui vous a semblé simple ;
- ce qui vous a semblé compliqué ;
- ce que vous avez cherché sans le trouver ;
- ce qui vous a surpris ;
- ce qui vous a donné envie, ou non, de revenir dans l'application.

Vous pouvez être totalement sincère.

Un problème, une incompréhension ou une critique nous est plus utile qu'une réponse destinée à nous faire plaisir.

Merci de nous aider à améliorer DABO.
