# DABO — UX Lisibilité V2

Ce correctif augmente la lisibilité du contenu à l'intérieur de l'application foyer : titres, noms de tâches/courses, métadonnées, boutons, formulaires et textes secondaires.

La barre de navigation inférieure validée en V1 conserve sa taille actuelle.
Le cockpit Admin n'est pas modifié.

## Installation
1. Décompresser le ZIP à la racine du dossier `dabo-app`.
2. Accepter le remplacement des 2 fichiers.
3. Lancer :

```powershell
npm run verify
```

## Fichiers remplacés
- `app/globals.css`
- `app/app/layout.tsx`
