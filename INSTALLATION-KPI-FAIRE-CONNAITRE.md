# DABO — KPI « Faire connaître DABO »

1. Dans Supabase > SQL Editor, exécuter le contenu de `supabase/migrations/20260908_app_share_events.sql` une seule fois.
2. Copier les fichiers du ZIP à la racine de `dabo-app` en acceptant les remplacements.
3. Lancer `npm run verify`.
4. Si PASS : commit GitHub Desktop, Push origin, attendre Vercel Ready.
5. En production, utiliser « Faire connaître DABO » une fois puis ouvrir `/admin` et Actualiser.

Mesures ajoutées :
- Partages déclenchés · 30 j
- Ambassadeurs · 30 j (utilisateurs uniques)
- Partages · total

Un partage natif annulé n'est pas compté. Une copie réussie est comptée. Aucune donnée sur le destinataire n'est collectée.
